# Contributor Profiles Directory

This directory contains profile JSON files for team members and trainees who complete the Zemen Git Sandbox exercise.

## Instructions
1. Copy `_template.json` to a new file named `<your-github-username>.json`.
   Example: `contributors/samuel-kebede.json`
2. Fill in the required fields:
   - `name`: Your full name.
   - `github_username`: Your GitHub account handle.
   - `role`: Your team or trainee focus (e.g., Frontend Developer, DevOps Intern).
   - `location`: Your current city and country.
   - `favorite_git_command`: Your favorite command (e.g. `git status -s`, `git add -p`).
   - `bio`: A short note on your engineering goals.
3. Verify your file format locally by running:
   ```bash
   npm test
   ```
4. Commit, push, and submit your Pull Request!
